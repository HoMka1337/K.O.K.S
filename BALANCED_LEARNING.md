# Сбалансированное обучение KoKs

## Что изменено

Автоматическое обучение по умолчанию отключено (`LIFE_AUTOLEARN_EVERY = 0`).
Запуск произвольного Python отключён (`ALLOW_CODE_EXECUTION = False`): рабочая
папка subprocess не является изоляцией ОС. Автоматические изменяющие команды
из ответа модели также блокируются; чтение и поиск доступны через инструменты.

Записи `/teach` и фрагменты веб-страниц сохраняются в
`data/learning_records.json` с источником, датой, идентификатором и
`verified: false`. Они не становятся обучающей истиной автоматически.
Команда `правильно <ответ>` сохраняет проверенное пользователем исправление.
Последнее проверенное исправление имеет приоритет. Для проверки веб-кандидата
задайте его вопрос в чате и введите `правильно <проверенный ответ>`.
Пустое исправление отклоняется.

`/train-now` использует проверенные исправления и `data/teacher_dialogs.txt`.
Старый `data/dialogs.txt` остаётся источником поиска ответов, но не считается
автоматически проверенным набором для `/train-now`. Его следует очистить от
ошибочных ответов. Явная CLI-команда `--train файл` считает указанный файл
подготовленным пользователем материалом; проверяйте его до запуска.

## Контроль качества

При первом обучении нужно минимум 10 разных вопросов. Сохраняется постоянный
`data/validation.json`: 10% примеров, минимум 2. Эти вопросы, в том числе
варианты с исправленными ответами, исключаются из обучения весов.
Можно заранее подготовить этот файл как JSON-массив строк `вопрос\nответ`.
Для содержательной оценки используйте значительно больше двух примеров:
старые знания, команды, исправления и корректные отказы от ответа.
Не удаляйте файл между сессиями, чтобы контрольный набор оставался постоянным.

Каждый запуск сравнивает исходную модель и кандидата по средней ошибке на
контрольных токенах. Принимается лучшая эпоха только со строго меньшей ошибкой.
При отказе, исключении или ошибке сохранения восстанавливаются исходные веса.
Принятый checkpoint записывается через временный файл и атомарную замену;
предыдущая рабочая версия находится рядом с суффиксом `.previous`.
В память возвращаются веса принятой лучшей эпохи.

Улучшение средней ошибки не гарантирует улучшение каждого ответа или
безопасности инструментов. Поведенческие тесты и ручная оценка обязательны
перед включением автономного изменения весов. Постоянный контрольный набор
нельзя бесконечно использовать как единственное доказательство качества.

## Новые данные и повторение

Счётчик `trained` увеличивается только для примеров принятого обучения.
При наличии ранее выученных примеров выбирается ориентировочно 20% новых и
80% старых; при недостатке старых размер новой части уменьшается. При первом
обучении используются доступные проверенные примеры. Новые выбираются с конца,
старые перемешиваются. Автообучение требует минимум `LIFE_MIN_GOOD_PAIRS` новых
проверенных примеров; веб-кандидаты этого условия не удовлетворяют.
Объём ограничен `LIFE_MAX_TRAIN_TEXTS`. Не увеличивайте число эпох вместо
проверки качества данных.

## Токенизатор и совместимость

Новые токенизаторы используют `<SEP>` для границ строк; запрос генерации не
заканчивается `<EOS>`. Старые токенизаторы без `format_version` загружаются
в прежнем формате (версия 1), без молчаливого изменения кодирования весов.
Для перехода старой модели на новый формат требуется отдельное обучение.
Новые checkpoints содержат отпечаток токенизатора; несовпадение блокирует загрузку.
Старые checkpoints без отпечатка проверяются по версии и размеру словаря.

## Проверка

`python -m unittest discover -s tests -v`

Исходные smoke-тесты создают состояние приложения: запускайте весь набор на
копии исходников, если нужно сохранить живые журналы и память без изменений.
Тесты нового обучения используют маленькую CPU-модель и временные каталоги.
